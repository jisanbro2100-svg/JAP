# JAP — GitHub APK Build Project

This project is prepared so GitHub Actions can build the Android APK in the cloud.

## Phone-only steps

1. Upload the **contents** of this folder to your GitHub `JAP` repository (do not upload the ZIP as a single file).
2. Commit the files to the `main` branch.
3. Open the repository's **Actions** tab.
4. Open **Build JAP APK**.
5. Tap **Run workflow** if needed.
6. Wait for the workflow to finish with a green check.
7. Open the completed workflow run and download the artifact named **JAP-debug-apk**.
8. Extract the artifact ZIP and install `app-debug.apk` on Android.
